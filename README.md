## Usage

Open a `Day-XX` folder, read its guide, install any imported third-party package, then run:

```bash
python main.py
```

Days 01–26 preserve projects from their original repositories. Days 27–30 are new capstones. Original repositories remain unchanged.

Never commit passwords, API keys, or bot tokens. Use environment variables for credentials.
